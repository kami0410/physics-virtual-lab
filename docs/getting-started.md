# 启动与安装

有三种用法，按需要选一种：

| 用法 | 适合 | 需要 Node.js | AI 助教 |
|---|---|---|---|
| [一键启动](#一键启动) | 自己的电脑上长期用 | 需要 | 全部服务都能用（内置中转） |
| [离线单文件版](#离线单文件版) | 拷给同学、机房、没网的电脑 | 不需要 | 大部分服务能直连；智谱需要另开中转 |
| [部署到网站](#部署到网站) | 老师给全班用、手机上用 | 只在构建时需要 | 同单文件版 |

---

## 一键启动

### 1. 安装 Node.js

到 <https://nodejs.org/zh-cn> 下载 **LTS（长期支持）版**，安装时一路“下一步”即可，不用改任何选项。需要 Windows 10 及以上、macOS 11 及以上。

> 官网下载慢时，可以用国内镜像：<https://npmmirror.com/mirrors/node/>，进入最新的 LTS 版本目录，Windows 下载 `node-vXX.X.X-x64.msi`，Mac 下载 `node-vXX.X.X.pkg`。

装好后可以检查一下：打开命令行（Windows 按 Win+R 输入 `cmd`），输入 `node -v`，能显示版本号就说明装好了。

### 2. 下载本项目

在 GitHub 页面点绿色的 **Code → Download ZIP**，解压到任意文件夹（路径里有中文、空格都没关系）。

会用 git 的话也可以：

```bash
git clone https://github.com/kami0410/physics-virtual-lab.git
```

### 3. 双击启动

| 系统 | 操作 |
|---|---|
| Windows | 双击 `启动实验室.cmd` |
| macOS | 第一次：右键 `启动实验室.command` → 打开 → 在弹出的提示里再点“打开”。以后直接双击即可 |
| Linux | 在项目文件夹里打开终端，运行 `sh 启动实验室.command` |

双击后会弹出一个命令行窗口，它依次做这几件事：

1. 检查有没有装 Node.js，没装会提示你去下载；
2. 检查实验室是不是已经在运行，如果是，直接打开浏览器，不重复启动；
3. 第一次运行时自动执行 `npm install` 安装依赖（一百多 MB，一两分钟）；
4. 启动本机服务器（地址 `http://127.0.0.1:5173/`），并自动用默认浏览器打开。

**这个命令行窗口要一直开着**，实验室才能用；用完直接关掉它就行。服务器只监听本机（127.0.0.1），局域网里的其他电脑访问不到。

服务器里同时内置了 AI 助教的中转（见 [AI 助教使用说明](ai-tutor.md#中转是什么什么时候需要)），所以这种方式下所有 AI 服务都能直接用，不需要另外配置。

### 常见问题

**第一次安装依赖很慢、或者失败**

多半是访问 npm 官方源慢。在命令行里运行下面这句，改用国内镜像，再双击启动：

```bash
npm config set registry https://registry.npmmirror.com
```

**Mac 提示“无法打开，因为无法验证开发者”**

用右键 → 打开，而不是直接双击；或者在“系统设置 → 隐私与安全性”底部点“仍要打开”。如果提示没有执行权限，在终端里进入项目文件夹运行 `chmod +x 启动实验室.command`。

**5173 端口被别的程序占用了**

程序会自动换一个端口（5174、5175……），命令行窗口里会显示实际地址，浏览器也会自动打开这个地址。注意：浏览器里保存的设置（AI 密钥、偏好）是按地址分开的，换了端口需要重新设置一次。

**页面卡顿**

实验页顶栏有“画质”选项，默认“自动”：会根据电脑性能自动降档。老电脑可以手动选“低”。有独立显卡的电脑，干涉、衍射图样会用显卡计算，快很多。

**浏览器要求**

最近两年内的 Chrome、Edge、Firefox、Safari 都可以。不支持 IE。

## 离线单文件版

适合拷到 U 盘、发给同学、在机房或没有网络的电脑上用。

在任何一台装了 Node.js 的电脑上，进入项目文件夹运行：

```bash
npm install            # 第一次需要
npm run build:single
```

生成的 `dist-single/index.html` 就是完整的实验室：一个约 5 MB 的文件，三维模型、公式字体、全部 64 个实验都在里面。双击用浏览器打开即可，**完全不需要联网，也不需要 Node.js**。

关于 AI 助教：单文件版里，Claude、DeepSeek、通义、Kimi、OpenAI、Gemini 等大部分服务可以直接连；智谱 GLM 不允许网页直接访问，需要在本机另外运行中转，见 [AI 助教使用说明](ai-tutor.md#中转是什么什么时候需要)。

## 部署到网站

想让全班同学用手机、平板直接打开网址就能做实验，可以部署成静态网站：

```bash
npm run build
```

把生成的 `dist/` 文件夹整个上传到任何静态网站空间即可，例如学校的 Web 服务器、GitHub Pages、Gitee Pages、Cloudflare Pages、Netlify 等。不需要数据库，也不需要后端程序。

网站版带有离线缓存：打开过一次以后，断网也能继续用。手机上的布局会自动调整（屏幕宽度不足 820 px 时）。

## 命令速查

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动开发服务器（`http://127.0.0.1:5173`，含 AI 中转），一键启动用的就是它 |
| `npm run build:single` | 构建离线单文件版 → `dist-single/index.html` |
| `npm run build` | 构建网站版 → `dist/` |
| `npm run preview` | 本地预览 `dist/`（也含 AI 中转） |
| `npm run relay` | 单独运行 AI 中转（127.0.0.1:8787），关窗口即停止 |
| `npm run relay:install` | 把 AI 中转设为开机自动在后台运行 |
| `npm run relay:uninstall` | 取消开机自启并停止中转 |
| `npm test` | 运行全部测试（物理模型验证 + 所有实验的自动化测试） |
